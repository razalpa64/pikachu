# Chess piece artwork

The twelve files in this folder (`wK.svg`, `wQ.svg`, … `bP.svg`) are the **"Staunty"**
chess set, used by lichess.org.

- **Author:** sadsnake1
- **Source:** https://github.com/lichess-org/lila/tree/master/public/piece/staunty
- **Licence:** CC BY-NC-SA 4.0 — https://creativecommons.org/licenses/by-nc-sa/4.0/

Pikachu is a personal, non-commercial project (see the site footer), so the
non-commercial clause is honoured. The files are shipped unmodified apart from
stripping an editor-only `style` attribute and adding `width`/`height="100%"`
so they scale to the board squares.

If this project ever needs a commercially licensed set, replace this folder with
a CC BY 4.0 set (e.g. `papercut` or `kiwen-suwi` from the same repository) and
keep every file name identical — nothing else has to change.
